HOW INSTALLATION WILL WORK

Install once.
Play as usual.

The first public release is coming soon. Once available, RideLink will run inside the game. No phone app or account is required.

  1. Close Fairground Online

    Once the first release is available, run its RideLink installer. Confirm the detected game folder or select it yourself.

  2. Set up the loader

    If needed, opt in to the tested BepInEx IL2CPP download. The installer verifies it and preserves your settings and other plugins.

  3. Launch and press F6

    Open RideLink from the in-game menu. The first loader startup may take longer while it prepares game assemblies.

SAME NETWORK. SECOND SCREEN.

Your PC hosts. Your phone connects.

Open the LAN address shown in the F6 menu or web Settings on your phone. Keep both devices on the same local network and leave the game running. Claim Mega Dance or Turaka to load its panel.

A LITTLE HELP

Questions at the gate.

The phone cannot connect

Use the PC's LAN URL, not localhost on the phone. Keep the game open, check Windows Firewall, and avoid guest Wi-Fi or hotspot client isolation. The installer offers an optional, explicitly approved local-subnet firewall rule.

Which languages are supported?

English and German follow the game's selected language. Other game languages use English for now. Choose Light, Dark or System appearance in web Settings. Choose this website’s language independently at the top right.

Will it change my game settings?

Updates preserve your configuration, saves and other plugins. An incompatible existing loader is not replaced automatically. Keep backups when managing game mods.

Is it secure to open the port?

RideLink is for a trusted local network. It checks local ownership before applying commands, but does not authenticate individual phones. Never forward its port to the internet.

Is this an official mod?

No. RideLink is an independent, unofficial Fairground Online mod and is not affiliated with or endorsed by the game's developers.

Where is the source code?

This repository is for the website and future releases/distribution only. No RideLink application source code is published here. The first public download is coming soon.
