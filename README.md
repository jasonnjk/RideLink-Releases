# RideLink

RideLink is an unofficial mod for Fairground Online. It lets operators control supported ride panels from another browser, phone or tablet on the same local network.

**First public release coming soon. No public download is available yet.**

Mega Dance and Turaka are supported in development. More rides are planned before the first public release.

This repository is for the website, releases and distribution only. No RideLink application source code is published here. Future installers and runtime packages will be attached to GitHub Releases, not committed to this repository. There is no production update manifest yet.

The website offers English and German, with automatic system light/dark appearance. The mod follows the game's language independently.

## GitHub Pages

In repository **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/docs**, then **Save**. The static site needs no build pipeline; docs/.nojekyll is included.
